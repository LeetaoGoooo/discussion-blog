四月随笔

By LeetaoGoooo on May 4, 2026

四月小结，但是不仅仅写给四月。本来想着五一第一天就把这篇小结写了的，不过当时有本书正在读，我有点轻微的强迫症，原谅我吧，直到才把这本书读完，然后小结也拖到今天。

不过我今天也惊喜的发现，四月底上架的两个 App 迎来了第一个付费用户，不过有点出于意料的是不是 Stars 那个软件，然后 LightYou 这个稍后阅读软件。

￼ 因为从我自己的视角来看， Stars 相对精美一点，可能更受女性的喜欢，然后女性的消费能力比较强，而 LightYou 则相对小众一点，另外也没有那么好看，就有了上述的推论，不过正因为是出乎意料，则更让人振奋一些，这不我正在着手安排 LightYou 的下个版本。不过可能 Stars 本身存在一点问题，我在五一前更新的了一个版本，做了点尝试，希望可以提高买断的转化率，这个就是后话了，需要一点的时间去验证了。

接着说，我之前也在自己的博客以及社交媒体上提到自己有做一款 Agent Todo 软件，经过几次迭代，然后我把整个软件都推倒了，再我把软件砍了几周之后，我看到了不少 Agent Todo 软件，它们的思路和最初的软件如出一辙，不是想说抄袭，这个不存在的，只是想夸自己，自己的思路稍微领先了它们一丢丢。注意，我说的是把软件推到了，不是说我彻底放弃了这个 Agent Todo 软件，我而在之前的基础我又有了一个新的想法。新的 Agent Todo 软件已经稳定运行了一周了，具体效果有没有上个阶段的 Todo 软件好，可能还需要一俩周的完整体验。不过在新的软件下已经完成了不少数量的 Todo 了，我的 Agent 们说感觉还不错 ￼

这会是我的 Agent Todo 软件最终形态吗？肯定不是的，因为还有一块版图没有加上，至少在我眼里这个阶段是这样子的，最后一块版本是我之前在之前的文章有提到的，我的另外一个项目 memox ，多 Agent 协作的底座，不过这个软件的功能也快让我砍的差不多了，从最初的几十个命令，砍到了只剩几个，但是还不够，我还得再砍几刀。

￼

说到 memox 这个就不得不说说，葫芦娃了，葫芦娃有一部分框架已经开源了，不过说句实话是阶段性产物，是自己想从头尝试搭建类似 openclaw 的 Agent 应运而出的，它让我学习了不少东西，不过后面也就没怎么维护了。这里是想说另外一件事情，我觉得还蛮有参考价值的。

之前我把葫芦娃接入到 IM 软件里去，是希望我人不在电脑前也可以给 Agent 安排工作，尝试了一段时间，我把这部分功能都移除了，不过在手机上编程其实是个很火热的趋势，claude，github copilot 最近 openai 也有了对应的手机端，就是为了可以让人可以随时随地工作。但是随时随地工作或者给 Agent 安排工作是对的吗？至少在我这里不是对的，当我离开电脑前，我应该去享受电脑之外的事情，所以我现在的原则就是当我离开电脑前，我就不再见缝插针地给 Agent 安排工作了，也不会去审查 Agent 的工作进度，专注当下。每一部分的时间有它对应的意义，而不是不知不觉地让它被工作浸没侵占。

另外一个变化是，减少上下文的切换，大块的时间做大块的事情，早期我和 AI 的协作模式是我不停地盯着 AI 工作，当它完成一个，我便紧锣密鼓地安排下一个，如果是一个项目倒是没太大的问题，但是如果是几个项目齐头并进，我感觉自己就像一个旋转的陀螺，在大脑里疯狂地切换上下文，偶尔我可以感觉我的大脑在“冒烟”。另外 AI 完成一个任务时间没有那么固定，有的时候你可能在等待地时间做些琐碎的事情，结果是你感觉很多事情被AI 冲击地七零八落，人更容易感觉疲惫。碎片化地时间不存在修养生息这一说。

为了避免这种情况，集中力量办大事，我会化很长的时间去拆解阶段性的任务，然后安排给 AI，然后集中去验收，最短的时间段位也是一个小时，这一个小时内，AI 安安静静地做它的事情，而我则安安静静地去忙自己的事情，我们互不打扰，以小时为单位进行循环，而我也得以从碎片化的时间抽身出来，可以去学习新的东西，去思考，精力也得以恢复，真可谓一举两得，当然任务的管理和拆解是一门学问，每个人的都可能有所不同，我也是花了不少时间去摸索，最终沉淀了一点东西，其实逻辑很简单，把每次任务进行打分，然后不断地去梳理这些完成好的任务的共性是什么，完美任务是追求，不要过于盲目，舍本求末。

最后的最后，读书要读书，也不一定是读书，要做可以让自己沉下心的事情，对我来说读书就是这样子的。AI 带来效率的同时也会让人浮躁，让人觉得自己无所不能，让人疲于奔命。之前短视频让人沉迷，现在 AI 同样也让人沉迷其中，这俩者如果稍微不注意结果是一样的，让人放弃思考，AI 是工具，我们要做的是使用工具，而不是畏惧工具，又或者成为工具的奴隶。

￼
