GitHub - MemPalace/mempalace: The best-benchmarked open-source AI memory system. And it's free.
The best-benchmarked open-source AI memory system. And it's free. - MemPalace/mempalace
 https://github.com/MemPalace/mempalace 这个项目我之前看了一下代码，整体的思路我觉得很有参考价值，给我一种原来可以这样子设计的，然后发现有人用 Rust 重写了 https://github.com/ZhangHanDong/mempal 了。 老早之前我做了 memox ，也是希望可以更好的去处理多 Agent 协作场景下，如何让另外一个 Agent 快速的 handoff，其中我觉得一个效果蛮好的场景就是让 Agent A 在自己的 session 下去教导 Agent B，但是一旦当接手这件事情在某个 Agent 撞到限额了，这种教导模式就会受阻，问题就变成了，如果把这些 session 通过一种方法蒸馏出来，也使用使用 raw session 的方法，直接让下个 Agent 去读上个 Agent 的 session 自己再去压缩，显然这种方法是个笨方法，有效果但是不好。所以最终的问题就变成了每次修改变成了是什么问题，为什么这么修改，涉及的范围有哪些，希望所有的文件的修改都是可追溯的，所有 Agent session 可以和 git history 那样子是时间为维度散落到每个文件里去，接着前段时间在群里分享了 https://github.com/mainline-org/mainline 这个项目，这俩天就在思考是不是可以把这些内容整合到一起，就可以让 Agent Session 真正的发挥作用起来。



BTW https://zhanghandong.github.io/mempalace-book/preface.html 还有这本书（我还没看）
